# Time in the Market

A small, offline-first Swedish trade-fair game about long-term investing and market timing.

Open `index.html` directly in a modern browser. No server, installation, API, or internet connection is required.

Developer checks:

```text
node scripts/run-tests.js
```

In the browser console, use `TimeMarket.runTests()` for the A–Q validation report and `TimeMarket.debugMarket(1000)` for generator calibration statistics.
